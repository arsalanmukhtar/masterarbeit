description=Census data dashboard for all Gemeinden of Baden-Württemberg
about=Charts, Gemeinde / Kreis / Land comparisons, thematic maps and PDF reports for official statistics (demography, education, forecasts, living, tourism, employment) of every Gemeinde in Baden-Württemberg. On first start the plugin downloads the census data once (a 49 MB GeoPackage from the project's GitHub releases) and then works offline, except for the OpenStreetMap basemap. No database or extra Python package is needed. Statistical data: Statistisches Landesamt Baden-Württemberg; boundaries: LGL BW; both under Datenlizenz Deutschland - Namensnennung - Version 2.0. See DATA_LICENSE.md.

changelog=
    2.1.2 Published under GPL-2.0-or-later; the census data is downloaded once on first start instead of being bundled, so the plugin can be installed and updated from the QGIS plugin repository; basemap choice (OpenStreetMap in three looks, the XYZ connections of the QGIS Browser, raster layers of the project) and QGIS layer properties for every layer of the dashboard map; tab labels and buttons no longer clip; redesigned PDF reports with a cover with maps and key figures, an at-a-glance page, one chart page per statistic with key figures, age pyramids, and the full numbers as CSV files beside the PDF; the report map has a legend, north arrow, scale bar, graticule and an overview inset; more basemaps in the Spatial Query tab (CARTO, Esri, OpenTopoMap); the legend fills the side panel; donuts of several values can show up to four years as concentric rings; redrawn checkboxes in the value list, toggled by clicking anywhere on a row.
    2.1.1 Opens at once, maximized, and loads each tab when it is first opened; light and dark theme with a toggle in the window; redesigned interface with the Inter font throughout and search in every dropdown; chart types line, area, bars, stacked bars, stacked area and donut; several values of a chart shown together on the Visualization tab; larger chart text, hover values and a table view for every chart; index view (first year = 100) to compare a Gemeinde with its Kreis and the state; Gemeinde profile with population, coloured ten-year trend, average age, area and density; chart export as image and data export as CSV; thematic maps on the dashboard with classes, legend and the rank of the selected Gemeinde, saved with their style; corrected labels for average age, households and accommodation statistics; redesigned PDF reports.
    2.0.0 Rewritten as a modular plugin for QGIS 3.22 to 4.x (Qt5 and Qt6); data bundled as a GeoPackage instead of a PostgreSQL server; window adapts to the screen size; searchable Gemeinde lists; map click identifies a Gemeinde; thematic layers as GeoPackage or Shapefile; no extra Python packages needed.
    1.0 Thesis version (PostgreSQL based).
